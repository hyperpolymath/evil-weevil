:toc:

== Tech Stack

* *Zig* — the kernel and the FFI layer (`src/core/`, `src/interface/ffi/`).
* *Idris2* — the ABI contract (`src/interface/Abi/`); the C header is generated from it.
* *C ABI* — the one interface every host and adapter speaks (`include/evil_weevil/ee.h`).
* Host languages (GDScript, C#, C++) appear only in adapters, never in the kernel.

See link:../../docs/decisions/0007-kernel-implementation-language.adoc[ADR-0007] for why.

== Test

Metadata and structure gates work today; behaviour tests arrive with the kernel.

[source,bash]
----

just test               # kernel tests (Phase 1)
just ci                 # the full gate
----

== Project Structure

[source]
----
evil-weevil/
├── src/core/                 # the host-agnostic kernel (empty until Phase 1)
├── src/interface/Abi/        # Idris2 ABI contract: layout, purity, exhaustiveness
├── src/interface/ffi/        # Zig implementation of the C ABI
├── include/evil_weevil/      # ee.h — generated from the Idris2 types, never hand-edited
├── tests/                    # Test suite, incl. the golden-replay corpus
├── docs/                 # Documentation
├── .machine_readable/    # Checkpoint files (STATE, META, ECOSYSTEM)
├── Justfile              # Task runner recipes
├── build/                # Build orchestration (just/, guix.scm, container/)
└── *_chora.deed          # repo deed: AI entry point (allocation + ply tree)
----

== Contractile Invariants

Read `.machine_readable/contractiles/must/Mustfile.a2ml` before making changes.
The invariants specific to this project, which no change may violate:

* the kernel never calls back into the host mid-tick (ADR-0004);
* integer and fixed-point arithmetic only in decision paths — no `libm` (ADR-0006);
* every struct crossing the ABI is size-checked and versioned (ADR-0005);
* no allocation inside the tick; arenas are supplied by the caller;
* `include/evil_weevil/ee.h` is generated — a hand edit is a defect.

All of them are asserted in CI, not merely written down.
